# Sistema de Inteligencia Territorial y Valoración Económica Ambiental

## Documentación académica — ESEIT

Proyecto individual de desarrollo tecnológico orientado a construir una herramienta para análisis geoespaciales, conectividad biótica y valoración económica ambiental, aplicable a estudios de consultoría en Colombia.

**Inicio:** 10 de septiembre de 2026  
**Dedicación:** 7–8 horas semanales  
**Primer hito académico:** 4 de noviembre de 2026  
**Horizonte estimado:** 24 semanas
